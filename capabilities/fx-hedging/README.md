
# FX Hedging — Scenario 18: Ship Propulsion

**Client:** U.S. ship-propulsion engineering firm  
**Transaction:** EUR 5,600,000 receivable from a Greek shipyard  
**Settlement:** 365 days  
**Functional currency:** USD

## Engagement Overview

This project evaluates the foreign exchange transaction exposure faced by a U.S. engineering firm expecting a EUR 5,600,000 payment from a Greek shipyard in 365 days.

Because the receivable is denominated in EUR, depreciation of the euro against the U.S. dollar would reduce the company's USD cash proceeds.

The analysis compares four hedging strategies:

1. No hedge
2. Forward hedge
3. Money-market hedge
4. EUR put option hedge

The objective is to evaluate cash-flow certainty, downside protection, upside participation, and the financial costs associated with each strategy.
